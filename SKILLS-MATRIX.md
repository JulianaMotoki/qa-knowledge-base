# QA Skills Matrix

Esta matriz acompanha minha evolução profissional, ajudando a identificar
conhecimentos consolidados, pontos que precisam de revisão e assuntos que
precisam ser estudados ou praticados.

## Status

| Status | Significado |
|---|---|
| 🟢 Consolidado | Conhecimento utilizado com segurança |
| 🔵 Praticando | Conheço, mas quero ganhar mais experiência prática |
| 🟡 Revisar | Já utilizei/estudei, mas preciso revisar |
| 🟠 Estudando | Conhecimento em desenvolvimento |
| 🔴 Aprender | Ainda preciso estudar |
